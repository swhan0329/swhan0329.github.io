책 내용

Chat·Work·Codex에서 시작하기

Chat은 질문과 생각 정리, Work는 결과물을 만드는 업무, Codex는 기술적인 작업 과정을 함께 확인하는 출발점으로 소개합니다. Work에서도 코드를, Codex에서도 문서를 다룰 수 있으며 실제 접근 범위는 환경과 권한에 따라 달라집니다.

Voice·Pet·Chrome·Sites

Voice와 Pet, Chrome 확장, Sites를 실제 화면과 함께 살펴봅니다. @대화 제목으로 이전 대화를 참조하고 여러 Gmail 계정을 구분해 업무를 이어가는 방법도 담았습니다.

모델 선택과 결과 검토·반복 업무

GPT-6 Astra를 Medium부터 사용해 조정하는 저자의 제안, 계정 사용량·리셋권 확인, 문서 검증 체크리스트와 별도 작업 검토, Goal·예약·스킬로 긴 작업과 반복 업무를 운영하는 방법을 정리합니다.

What Is Inside

Starting in Chat, Work, or Codex

Use Chat to explore questions, Work to create deliverables, and Codex to inspect technical work. Work can handle code and Codex can create documents; access depends on your environment and permissions.

Voice, Pet, Chrome, and Sites

Explore Voice, Pet, the Chrome extension, and Sites through screenshots. Reference prior conversations by title and distinguish multiple Gmail accounts when continuing work.

Model Choices, Output Review, and Repeated Workflows

The author suggests starting with GPT-6 Astra at Medium and adjusting as needed. The guide also covers usage and reset credits, document checklists, review in a separate task, and Goal, scheduling, and Skills.
